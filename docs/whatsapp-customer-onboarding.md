# Customer WhatsApp onboarding

Customer owners, admins, and managers connect WhatsApp Business from the Xvond customer portal. Xvond exchanges the Meta authorization code server-side, subscribes the app to the selected WABA, stores encrypted channel credentials, and binds the phone number to the selected AI employee.

Production requires `META_APP_ID`, `META_APP_SECRET`, `META_WHATSAPP_CONFIG_ID`, and `META_WHATSAPP_VERIFY_TOKEN` in the server environment.
